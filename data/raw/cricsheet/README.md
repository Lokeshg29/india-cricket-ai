This is the source archive, retained as downloaded. The importer filters to men's international matches involving India and maps international T20 to T20I. Domestic T20 is excluded. Normalized output is written separately under `data/processed/cricket/` and is marked `HISTORICAL_DATA`; dashboard JSON exports remain synthetic `DEMO DATA`.
